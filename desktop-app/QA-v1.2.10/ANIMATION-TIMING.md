# 咕咕龙 v1.2.10 动作节奏验收

## 调整目标

- 默认状态更像安静陪伴，而不是持续表演。
- 情绪与礼貌动作稍慢，能看清动作过程。
- Codex 执行状态保持及时，不牺牲工作反馈。

## 最终节奏

| 状态 | 每帧间隔 | 说明 |
| --- | ---: | --- |
| 默认站立 | 0.25 秒 | 主站姿每轮先保持约 2 秒 |
| 挥爪 | 0.24 秒 | 比旧版慢约 33% |
| 大哭 | 0.24 秒 | 比旧版慢约 33% |
| 暴怒跺脚 | 0.22 秒 | 比旧版慢约 22% |
| 等待 | 0.26 秒 | 比旧版慢约 44% |
| 执行中 | 0.18 秒 | 保持原速 |
| 点赞 | 0.24 秒 | 比旧版慢约 33% |

## 不变项

- 动作精灵图、菜单、拖动、尺寸、气泡频率、Codex 状态映射均未改变。
- 鼻子闪光仍不存在。
