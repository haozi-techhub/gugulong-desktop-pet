# 咕咕龙桌宠 v1.3.0 跨平台验收记录

## macOS 原生版

- Release 编译通过，`Info.plist` 校验通过。
- 可执行文件为 arm64，最低系统版本为 macOS 13.0。
- ad-hoc 深度签名校验通过。
- 运行、等待、完成、失败、损坏五类 Codex session fixture 映射通过。
- 动画时序自测通过：默认主姿态约 2 秒，手动动作保护 12 秒。
- 新构建的 v1.3.0 可执行文件实际启动成功；功能代码与已完成真实 UI 验收的 v1.2.12 相同，仅升级版本号。

## Windows 跨平台版

- Electron 43.3.0 Windows x64 运行时 SHA-256 与 Electron 官方 `SHASUMS256.txt` 一致。
- 应用逻辑自测通过：七种动作、五档尺寸、五类 Codex session fixture、过期与损坏数据降级。
- 不包含 Codex 额度模型、入口或解析逻辑。
- Windows 产物为 PE32+ GUI x86-64，`app.asar` 只包含运行代码与角色资源，不包含开发依赖。
- 使用相同 Electron 代码在 macOS arm64 实际启动并完成真实界面验收：
  - 身体右键菜单可打开。
  - 默认、挥爪、大哭、暴怒跺脚、等待、执行中、点赞均通过菜单切换并显示对应动作。
  - 50% 与 200% 尺寸切换成功。
  - 拖动后位置从 `(1128, 436)` 更新为 `(1028, 336)` 并持久化。
  - 设置窗口显示置顶、悬停大哭、气泡、Codex 联动和五档尺寸。
  - 右键菜单“退出咕咕龙”后测试进程以 0 退出。

## 未覆盖风险

- 当前环境没有 Windows 实机，因此没有在 Windows 10/11 上进行最终人工点击与系统托盘验收。
- Windows 包未购买商业代码签名证书，首次运行可能触发 SmartScreen。
- macOS 包使用 ad-hoc 签名，未做 Apple Developer ID 公证。
