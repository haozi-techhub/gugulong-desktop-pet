# 咕咕龙桌宠 macOS 版 v1.4.5

咕咕龙是一款可独立安装和转发的 macOS 桌面宠物，也是你的 Codex 本地搭子。它会常驻桌面，以动作和“咕咕嘎嘎”气泡反馈 Codex 的执行、等待、完成与失败状态。

## 系统要求

- Apple Silicon Mac（M1/M2/M3/M4 及后续机型）
- macOS 13.0 或更高版本
- 如需 Codex 联动，需在同一台 Mac 上使用 Codex

## 安装与启动

1. 解压 `咕咕龙-macOS.zip`。
2. 将 `咕咕龙.app` 拖入“应用程序”文件夹。
3. 首次启动时，右键 `咕咕龙.app`，选择“打开”，再确认一次。

当前分发包为 ad-hoc 签名，未做 Apple Developer ID 公证，所以首次打开需要上述操作。之后可正常双击启动。

## 怎么使用

- 左键按住咕咕龙身体并拖动：移动桌宠，位置会自动保存。
- 右键咕咕龙身体：打开完整控制菜单。
- 点击菜单栏中的咕咕龙头部剪影：即使隐藏桌宠，也能打开同一套控制菜单。顶部 Logo 直接采用确认后的恐龙头轮廓，不带外层圆角方框，保留双背刺、粗眉、大眼、鼻孔和七颗牙，并自动适配浅色/深色菜单栏。Logo 使用 20pt 可见尺寸，与相邻原生菜单栏图标保持同等级大小。
- 鼠标移入身体：默认触发大哭；移开后恢复之前的状态。
- “咕咕嘎嘎”会偶尔以紧凑的奶油色胶囊气泡出现在咕咕龙左上角；气泡减少留白和描边厚度，保留圆润描边字、小星星与指向尾巴，不拦截拖动、右键和悬停。
- 气泡单次停留约 1.6 秒；普通互动每六次才出现一次，并设有 10 秒冷却时间，避免频繁打断工作。
- 启动欢迎气泡只在首次运行显示一次，后续重启不再自动弹出。
- 大哭动画只保留眼泪、委屈表情和身体动作；鼻子始终保持原始颜色，不添加闪光、发亮或发光效果。

右键菜单和菜单栏都可以：

- 切换默认、挥爪、大哭、暴怒跺脚、等待、执行中、点赞。
- 切换 50%、75%、100%、150%、200% 尺寸。50% 档位的宠物窗口为 `96×104` 点，仍保留完整拖动和右键命中区域；气泡维持最低可读尺寸。
- 显示或隐藏桌宠。
- 打开设置窗口。
- 退出咕咕龙。

应用包直接使用彩色毛绒咕咕龙头像作为 Finder 产品图标，方便在“应用程序”、Finder 和分享压缩包中识别。

默认状态以安静站立为主：每轮会先稳定保持主站姿约 2 秒，再完成轻微眨眼/呼吸循环。挥爪、大哭、暴怒跺脚、等待和点赞采用更舒缓的逐帧速度；只有“执行中”保持较快节奏，确保 Codex 工作反馈仍然及时。

手动点击任一动作后会立即显示，并保留 12 秒，不会被后台 Codex 状态立刻覆盖；预览结束后会自动恢复 Codex 联动。

## 设置

设置窗口支持：

- 始终置顶
- 鼠标悬停时大哭
- 显示“咕咕嘎嘎”气泡
- 跟随 Codex 任务状态

尺寸、位置、置顶、悬停、气泡、Codex 联动开关和最后形态都会保存在本机，下次启动自动恢复。

## Codex 联动

咕咕龙每 3 秒检查本机最新的主任务 session，并忽略 subagent 与过期 session：

- 任务开始：执行中
- 请求权限或确认：等待
- 任务完成：点赞
- 任务失败：大哭
- 没有活动任务：默认

## 隐私说明

- 仅在本机读取 `~/.codex/sessions/**/*.jsonl`。
- 不上传 session 或对话内容。
- 不调用未公开接口。
- 不需要登录额外账号。

关闭“跟随 Codex 任务状态”后，桌宠不会再根据 session 自动切换动作。

## 完全退出

从咕咕龙右键菜单或菜单栏选择“退出咕咕龙”。如果桌宠已隐藏，请从菜单栏进入。退出会同时停止 session 监听和所有动画计时器。

## 验证下载文件

在终端进入解压目录后执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

显示 `OK` 代表文件与发布版本一致。

## 本地构建

```bash
cd desktop-app
sh build.sh
```

产物位于 `desktop-app/build/咕咕龙.app`。构建脚本使用系统 `clang` 和 AppKit，不依赖第三方运行库。

## 常见问题

### 桌宠被隐藏后找不到

点击菜单栏“咕咕龙”，选择“显示/隐藏宠物”。

### 首次打开被 macOS 拦截

右键应用选择“打开”。如果仍被拦截，可到“系统设置 → 隐私与安全性”确认打开。
