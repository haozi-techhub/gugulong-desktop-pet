# 咕咕龙动作与台词

精灵图采用 Codex v2 的 8×11 atlas（1536×2288）。所有宿主可显示的台词统一为：**咕咕嘎嘎**。文字气泡没有绘制进精灵图，避免透明边界和切片污染；宿主如支持气泡，可将该短语作为气泡文案。

| 状态 | 动作语义 | 气泡文案 |
|---|---|---|
| `idle` | 轻微皱眉、眨眼与身体呼吸 | 咕咕嘎嘎 |
| `running-right` | 短腿向右小跑 | 咕咕嘎嘎 |
| `running-left` | 短腿向左小跑（由右跑动作安全镜像） | 咕咕嘎嘎 |
| `waving` | 挥动小爪子 | 咕咕嘎嘎 |
| `jumping` | 暴怒跺脚：眉毛压低、脸变红、烟雾贴身 | 咕咕嘎嘎 |
| `failed` | 委屈哭哭、肩膀发抖 | 咕咕嘎嘎 |
| `waiting` | 紧张等待并左右张望 | 咕咕嘎嘎 |
| `running` | 身体前倾，认真执行任务 | 咕咕嘎嘎 |
| `review` | 完成后开心举爪/点赞 | 咕咕嘎嘎 |
| `look` | 16 个方向的注视动画（000–337.5，每 22.5°） | 咕咕嘎嘎 |

`look` 方向行分布在第 10、11 行（0-based row 9、10），标准动作占前 9 行。气泡、背景场景和道具均不嵌入 spritesheet。
